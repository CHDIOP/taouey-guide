# Contribuer à ce guide

Merci de vouloir améliorer la documentation utilisateur de Taouey ! 🙌

## Comment contribuer

1. **Forkez** ce dépôt
2. Créez une branche : `git checkout -b amélioration/nom-de-votre-sujet`
3. Faites vos modifications dans le dossier `docs/`
4. Vérifiez que le Markdown est bien formaté (titres, blocs de code, tableaux)
5. Ouvrez une **Pull Request** en décrivant clairement ce que vous changez et pourquoi

## Types de contributions bienvenues

- Corrections d'erreurs techniques ou de coquilles
- Exemples de scripts SLURM pour des cas d'usage spécifiques (IA, bioinformatique, simulation climatique, etc.)
- Retours d'expérience d'utilisation réelle du cluster
- Traductions (wolof, anglais...)
- Nouvelles entrées de FAQ basées sur des questions réelles

## Ce qu'il ne faut PAS inclure

- Identifiants, mots de passe, clés SSH ou toute information d'accès personnelle
- Adresses IP internes ou détails d'infrastructure sensibles non publics
- Informations non vérifiées présentées comme officielles

## Signaler un problème

Utilisez les [issues GitHub](../../issues) avec le modèle approprié (bug de documentation, suggestion, question).

## Code de conduite

Soyez respectueux et constructif. Ce projet sert la communauté scientifique et technique sénégalaise et ses partenaires.
